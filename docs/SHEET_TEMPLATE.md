# 구글 시트 구조

웹페이지는 구글 시트를 그대로 읽습니다. 시트를 고치고 페이지를 새로고침하면 반영됩니다.

현재 연결된 시트의 탭 구성입니다. 탭 이름을 바꾸면 `config.js` 의 `tabs` 도 같이 고쳐야 합니다.

| 탭 | 역할 | 웹에서 읽음 |
|---|---|:--:|
| `00_설정` | 제목·통화·지도 중심 | ✅ |
| `01_일정` | 원본 백업 | — |
| `01_일정_Day1` ~ `Day4` | 날짜별 일정 | ✅ (순서대로 합쳐서 표시) |
| `02_맛집` | 맛집 목록 | — |
| `03_준비물` | 준비물 체크리스트 | ✅ |

날짜가 늘면 `01_일정_Day5` 탭을 만들고 `config.js` 의 `itinerary` 배열에 추가하면 됩니다. 아직 안 만든 탭이나 빈 탭은 조용히 건너뜁니다.

---

## `00_설정`

`키` / `값` 두 열입니다. **헤더 행은 없어도 됩니다.** 키에 공백이 있어도 됩니다 (`여행 제목` = `여행제목`).

| 키 | 값 | 설명 |
|---|---|---|
| `여행제목` | `미야코지마🐳` | 화면 맨 위 제목 |
| `부제` | `2026.09.03 – 09.06` | 제목 아래 작은 글씨 |
| `시작일` | `2026-09-03` | `9/3` 처럼 연도 없는 날짜를 읽을 때의 기준이 됩니다 |
| `종료일` | `2026-09-06` | |
| `통화` | `JPY` | 통화기호가 없을 때 씁니다 |
| `통화기호` | `¥` | 금액 앞에 붙습니다 |
| `시간대` | `Asia/Tokyo` | "오늘" 판정 기준 |
| `지도중심` | `24.7900, 125.2800` | 지도 첫 화면. **미야코지마 좌표입니다** |
| `지도줌` | `11` | 클수록 확대 |

## `01_일정_DayN`

```
날짜   시간   구분   일정   이동수단   좌표   구글 맵 위치   비용   메모   관련 링크
```

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `날짜` | **A1 셀에 `날짜` 라고 넣어주세요.** 비어 있어도 값이 날짜면 알아서 찾지만, 넣는 편이 확실합니다 | `2026-09-03` |
| `시간` | 시작 시각. 비우면 "시간 미정"으로 표시되고 그 날의 맨 뒤로 갑니다 | `08:25` |
| `구분` | `이동` 🚕 `식사` 🍽️ `관광` 📷 `쇼핑` 🛍️ `숙박` 🛏️ `휴식` ☕ | `관광` |
| `일정` | 일정 이름 | `요나하마 비치` |
| `이동수단` | **이 일정에 도착하는 수단** (아래 참고) | `택시` |
| `좌표` | `위도, 경도`. 지도 핀과 길찾기에 씁니다 | `24.7421182, 125.2527899` |
| `구글 맵 위치` | 시트에 모아둔 구글 지도 링크. 「📍 지도」 버튼이 이 주소로 열립니다 | `https://maps.app.goo.gl/...` |
| `비용` | 숫자. 쉼표·`¥`·`엔` 이 섞여도 읽습니다 | `600` |
| `메모` | 자유 메모 | `선셋` |
| `관련 링크` | **URL만.** 한 칸에 여러 개를 줄바꿈으로 넣어도 됩니다 | `https://blog...` |

### 이동수단은 "여기에 어떻게 갔는가"

시트에 적으신 방식 그대로 해석합니다. `요나하마 비치` 행의 `택시` 는 **숙소 → 요나하마 비치**를 택시로 간다는 뜻이고, 두 일정 사이에 뜨는 길찾기 버튼이 그 구간을 그 수단으로 엽니다.

| 적는 값 | 구글 지도 경로 |
|---|---|
| `도보`, `걷기` | 도보 |
| `전철`, `지하철`, `버스`, `공항버스`, `대중교통` | 대중교통 |
| `택시`, `자동차`, `렌터카` | 자동차 |
| `자전거` | 자전거 |
| `비행기`, `항공` | **길찾기 버튼 없음** (구글 지도가 항공 경로를 못 냅니다) |
| (비움) | 대중교통 |

### 좌표 넣는 법

구글 지도에서 장소를 **우클릭** → 맨 위 숫자를 클릭하면 `24.7421182, 125.2527899` 형태로 복사됩니다.

`maps.app.goo.gl` 단축링크에는 좌표가 들어 있지 않아, **링크만으로는 지도 핀이 안 찍힙니다.** 링크는 `구글 맵 위치` 칸에 두고, 좌표는 `좌표` 칸에 따로 넣어주세요. 둘 다 있으면 가장 좋습니다.

좌표가 없어도 나머지는 정상 동작합니다. 지도 핀과 그 구간 길찾기만 빠집니다.

## `03_준비물`

`준비물` 한 열만 있어도 동작합니다. 아래 열을 더하면 쓰임새가 늘어납니다.

```
구분   준비물   담당자   메모
```

| 컬럼 | 설명 |
|---|---|
| `구분` | `서류` `의류` `물놀이` `전자기기` `의약품` 등. 이 단위로 묶여서 표시됩니다. 비우면 `기타` |
| `준비물` | 항목 이름 |
| `담당자` | 공용 물품 분담용. 이름이 배지로 붙습니다 |
| `메모` | 수량이나 주의사항 |

웹에서는 체크박스가 달린 목록으로 나오고, 체크 상태는 **그 브라우저에만** 저장됩니다. 서버가 없어서 일행끼리 공유되지는 않습니다. 같이 보시려면 시트에 체크 열을 두고 관리하세요.

## 서식 관련

날짜·시간 칸은 **서식 → 숫자 → 일반 텍스트** 로 통일해 두는 걸 권합니다.

한 열 안에서 어떤 셀은 텍스트, 어떤 셀은 시각 값으로 저장되면 구글이 CSV로 내보낼 때 한쪽을 빈 칸으로 지워버리는 경우가 있습니다. 웹에서는 이 문제를 우회하도록 처리해 두었지만, 서식이 섞여 있으면 시트에서 정렬·필터를 쓸 때 헷갈립니다.

---

## 시트 공개 설정

브라우저가 시트를 직접 읽으므로 읽기 권한이 열려 있어야 합니다.

**공유 → 일반 액세스 → `링크가 있는 모든 사용자` → 역할 `뷰어`**

이 사이트와 시트는 공개입니다. 여권번호·연락처처럼 노출되면 안 되는 정보는 넣지 마세요.

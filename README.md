# 여행 일정 웹

> 📋 **작업을 이어서 하신다면 [PROGRESS.md](PROGRESS.md) 를 먼저 보세요.**
> 어디까지 했고 다음에 뭘 해야 하는지, 그리고 다시 만나면 헷갈릴 함정들이 정리돼 있습니다.

구글 시트에 적은 여행 일정을 웹페이지로 보여줍니다.
**시트를 고치고 페이지를 새로고침하면 바로 반영됩니다.** 서버도, DB도, 빌드 과정도 없습니다.

```
Google Sheets ──[브라우저가 CSV를 직접 읽음]──► 정적 페이지 (GitHub Pages)
```

> ### ⚠️ 사이트도 시트도 공개입니다
>
> 브라우저가 구글 시트를 직접 읽는 구조라, **시트 주소는 반드시 브라우저에 전달됩니다.**
> 저장소에서 지우거나 인코딩해도 개발자도구 네트워크 탭에 그대로 보입니다. 숨길 수 없습니다.
>
> 그래서 시트는 "링크가 있는 모든 사용자 · 뷰어"로 열려 있어야 하고, 웹에 안 나오는 탭까지
> 링크만 알면 전부 보입니다. **여권번호·연락처·카드번호·예약 확인 링크는 시트에 넣지 마세요.**
>
> 꼭 넣어야 하는 링크는 [비밀번호로 잠글 수 있습니다](docs/SHEET_TEMPLATE.md#개인-정보가-담긴-링크-잠그기).
> 시트에는 암호문만 들어가고 원래 주소는 코드 어디에도 남지 않습니다.
>
> 시트를 진짜 비공개로 돌리려면 Apps Script를 프록시로 두는 방법이 있습니다. 지금은 쓰지 않습니다.

## 화면

- **일정** — 날짜별 타임라인, 지도(핀 + 동선), 구간별 구글 지도 길찾기 버튼
- **예산** — 구분별·일자별 지출 집계
- **예약** — 항공·숙소 카드

여행지 기준으로 오늘 날짜가 자동 선택되고, 브라우저 탭으로 돌아오면 알아서 다시 불러옵니다.

## 1. 로컬에서 먼저 보기

시트를 아직 안 만들었어도 예시 데이터로 바로 확인할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다.

> `index.html` 을 파일로 직접 열면(`file://`) 브라우저 보안 정책 때문에 데이터를 못 읽습니다. 반드시 위처럼 서버로 띄우세요.

## 2. 구글 시트 연결

1. **[docs/SHEET_TEMPLATE.md](docs/SHEET_TEMPLATE.md)** 를 보고 시트를 만듭니다
   (`sample/*.csv` 를 **파일 → 가져오기** 로 올리면 가장 빠릅니다)
2. 시트 **공유 → 링크가 있는 모든 사용자 → 뷰어** 로 변경
3. `config.js` 의 `sheetId` 에 시트 ID를 넣습니다

```js
export const CONFIG = {
  sheetId: '1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890',
  ...
};
```

`sheetId` 가 비어 있으면 자동으로 `sample/` 예시 데이터를 씁니다.

## 3. GitHub Pages에 올리기

**저장소 만들기** — GitHub에서 새 저장소를 만듭니다. **Public** 이어야 무료로 Pages를 쓸 수 있습니다.

**올리기**

```bash
git init
git add .
git commit -m "여행 일정 웹 초기 구성"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

> git 사용자 정보가 없으면 커밋 전에 한 번 설정해야 합니다.
> ```bash
> git config --global user.name "이름"
> git config --global user.email "메일주소"
> ```

**Pages 켜기** — 저장소 **Settings → Pages → Source** 를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)` 로 두고 저장합니다.

1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
모든 경로가 상대경로라 저장소 이름이 무엇이든 그대로 동작합니다.

**현재 배포된 주소: <https://jiakeem04.github.io/mddtrip/>**

일정만 바꿀 때는 구글 시트만 고치면 됩니다. 이 저장소를 다시 올릴 필요가 없습니다.
코드나 디자인을 고쳤을 때만 `git push` 하면 1~2분 뒤 반영됩니다.

## 잘 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| `시트 공유를 "링크가 있는 모든 사용자"로…` 배너 | 시트가 비공개입니다. 공유 설정을 바꾸세요 |
| `'일정' 탭을 읽지 못했습니다` | 탭 이름이 `config.js` 의 `tabs` 와 다릅니다. 공백·오타 확인 |
| 지도에 핀이 없음 | `좌표` 칸이 비었습니다. 구글 지도에서 우클릭 → 좌표 복사 |
| 날짜가 이상하게 나옴 | 시트의 날짜 칸을 **서식 → 숫자 → 일반 텍스트** 로 두세요 |
| 시트를 고쳤는데 그대로 | 우측 상단 새로고침 버튼(⟳)을 누르세요. 구글 쪽 캐시로 잠깐 늦을 수 있습니다 |
| 예산이 비어 있음 | `비용` 칸에 숫자가 없습니다 |

## 참고

- 지도는 **Leaflet + OpenStreetMap**, 길찾기는 **구글 지도 URL 규격**을 씁니다. **API 키가 필요 없습니다.**
- 길찾기 버튼은 모바일에서 구글 지도 앱으로 열려 실시간 환승·경로 안내로 이어집니다.
- 구글 지도는 경유지를 9곳까지만 받습니다. 하루 일정이 그보다 많으면 화면에 몇 곳이 빠졌는지 알려줍니다.
- 금액은 시트에 적힌 그대로 더합니다. 환율 환산은 하지 않습니다.
- 이 사이트와 시트는 **공개**입니다. 여권번호·연락처 같은 정보는 시트에 넣지 마세요.
